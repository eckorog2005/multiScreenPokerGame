# 13: Host controls on the Player Device

Status: ready-for-agent
Blocked by: 10, 11

## What

Admin controls shown on the Host's phone only.

## Acceptance criteria

- [ ] Before the first Hand, the Host can set the starting stack, the blinds and the turn timer (off or a number of seconds), then press "Deal" to start.
- [ ] Between Hands, the Host can pause and resume auto-dealing and change the blinds (the change applies from the next Hand).
- [ ] The Host can remove a Player, after confirming.
- [ ] When it's a disconnected Player's turn, the Host gets a "Fold for <name>" button.
- [ ] The Host can hand the role to another Player.
- [ ] Any Player's phone shows "Claim Host" once the Host has been disconnected for more than 60 seconds.
- [ ] The Host can end the Game, after confirming, which shows the Standings on the Table.
