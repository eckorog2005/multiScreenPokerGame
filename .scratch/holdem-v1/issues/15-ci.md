# 15: CI for lint, tests and build

Status: resolved
Blocked by: 01, 02

## What

A GitHub Actions workflow that runs on pushes and pull requests to `main`.

## Acceptance criteria

- [x] The workflow installs with pnpm (via corepack, with a cached store) on Node 22 and 24.
- [x] It runs `pnpm lint`, `pnpm test` and `pnpm build`, and fails on any error.
- [x] Formatting is checked with one formatter (e.g. Prettier or oxfmt) configured at the repo root, and existing files are reformatted in a separate commit.
